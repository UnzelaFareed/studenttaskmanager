
# Student Task Manager

A simple Python console application for managing student tasks.

## Features
- Add tasks with unique IDs.
- Reject empty task titles.
- Display all tasks.
- Mark tasks as completed.
- Delete tasks using task IDs.

## Requirements
- Python 3

## How to Run
1. Clone the repository:
   `git clone https://github.com/UnzelaFareed/studenttaskmanager.git`
2. Open the project folder.
3. Run:
   `python main.py`

## Run Unit Tests
```bash
python -m unittest discover -s tests -v
```

## Project Structure
- `main.py` – Application menu and user interaction.
- `task_manager.py` – Task management functionality.
- `tests/` – Unit tests.
- `docs/userguide.md` – User guide.
- `.github/workflows/` – GitHub Actions workflow.
